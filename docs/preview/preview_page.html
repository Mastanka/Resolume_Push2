Techno banks

Sixteen SEQ patterns in four banks, built on how Berlin, Detroit, club and warehouse techno place their drums. Each pattern is a recipe: the rhythm is fixed, which bar a hit lands on is drawn at random, and five macros bend it into variations. Type another bar layout to see the same recipe on a different rig.

What each bank takes from the music

Left to right inside every bank: minimal, groove, peak, and kick out. When the DJ pulls the kick, jump to column 4; when it comes back, go to 2 or 3. The pattern switches on the next bar, like on the Push. D means a dominant (long) bar, S a secondary (short) one; on a rig where all bars are alike, about a third of them take the D role, spaced out and mirrored.

Loading them into SEQ

  1. Type your rig, left to right, as you see it from the front: D for a long bar, S for a short one, or U9 for nine alike bars. Pads 1–N have to be your bars in that order; Show pads on Bar Chaser displays the numbers.
  2. Set the macros and reshuffle until each pattern looks right, then Copy YAML and paste it over techno_banks.yaml.
  3. Stop the bridge (it rewrites chases.yaml on every edit), run python merge_banks.py next to push_resolume_bridge.py, start the bridge. Row 5 holds P1–P8, Shift + row 5 holds P9–P16. Set Scale to 1/16.
  4. Put Bar Chaser on four layers set to Track 1–4. A flat white or slow gradient clip suits T1 and T2; give T3 and T4 something with movement.
  5. The source line on each pattern (recipe, seed, macros) is for the bridge's coming re-fit feature; today's bridge ignores it.
